# CAMS-DOC Feature Issues Review

## Summary

This review covers the CAMS Helm chart (`cams/appdeployer/cams/`), its GCP Marketplace schema, the test deployer (`cams/apptest/deployer/`), and the top-level `README.md`/`LICENSE`. The chart is functionally complete for a basic install, but the review surfaced a working default-values bug that breaks `helm template`/install for Java Tenant Management, several documented operational commands (status checks, backup/restore, uninstall cleanup, internal access) that reference Kubernetes label selectors and Service names that do not exist anywhere in the templates, hardcoded production-looking secrets (Gmail credentials, RabbitMQ password, Keycloak client secret, LiteLLM keys) committed directly in template source rather than sourced from configurable/generated values, a documented custom-hostname feature (Keycloak) and a custom Postgres-config feature that are both wired up as dead code (values/ConfigMaps that nothing reads, or files that don't exist), missing health probes on Nginx and PostgreSQL, and overly broad RBAC granted to the Nginx service account. Findings below are grouped roughly by severity; each was verified directly against the file contents rather than inferred.
